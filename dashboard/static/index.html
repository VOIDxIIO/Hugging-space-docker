1. Hugging Face Free Tier Rules

  • Total Spaces: You can create as many Space repositories as you want. There is no hard cap on the number of spaces in your account profile.
  • Simultaneous Running Spaces: Hugging Face allows multiple free Spaces to run simultaneously. Typically, you can run between 5 to 10 free Docker Spaces actively at the same time on a single account before hitting concurrent resource limits.
  • Multi-Account Scaling: If you need 20, 50, or 100+ separate browser nodes, you can simply create multiple free Hugging Face accounts and deploy this identical repository to each account!

2. Auto-Sleep & 24/7 Keep-Alive Strategy

By default, Hugging Face free Spaces automatically enter Sleep Mode after 48 hours of inactivity (no incoming web traffic).

How to keep it running 24/7 forever:

Set up an external free HTTP pinger to ping your Space URL every 10–15 minutes:

  1. Register a free account at UptimeRobot.com or cron-job.org.
  2. Add a monitor pointing to your public Space URL: https://<username>-<space-name>.hf.space/api/status.
  3. Set the interval to every 10 minutes. Because the ping receives a 200 OK response, Hugging Face considers the space active and it will never sleep!

3. How to Deploy Multiple Instances in 60 Seconds

  1. Go to huggingface.co/new-space.
  2. Set Space SDK to Docker (Blank).
  3. Under repository, link or push this GitHub repo, or click Duplicate Space directly in Hugging Face!
  4. Repeat to launch Node 2, Node 3, Node 4, etc.
